# Built-in soundtrack

`gaylaxy-soundtrack.mp3` is the 18.67-second soundtrack from the project owner's supplied reference video, bundled at their request. It is stored locally with the app and can be replaced or removed in the Sound tab.

The provided WAV was encoded as MP3 at 192 kbps with its original timing. No private profile pictures or reference video are bundled. This soundtrack retains its original rights; the software and flag licenses do not apply to it.
